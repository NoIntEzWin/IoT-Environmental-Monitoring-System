# IoT Environmental Monitoring System

This project is an IoT-based environmental monitoring system developed for my bachelor thesis.

## Description

The system collects environmental data using multiple sensors and sends the values to a local web server through Wi-Fi.

## Monitored parameters

- Temperature
- Humidity
- Pressure
- Air quality
- Gas level
- Noise level

## Hardware used

- Arduino Mega 2560
- ESP8266 NodeMCU
- DHT11 sensor
- BME280 sensor
- MQ135 air quality sensor
- MQ2 gas sensor
- KY-037 sound sensor

## Software used

- Arduino IDE
- PHP
- MySQL
- XAMPP
- phpMyAdmin

## System architecture

Sensors → Arduino Mega → ESP8266 → Wi-Fi → Local Web Server → MySQL Database → Web Dashboard

## Features

- Real-time sensor readings
- Wireless data transmission
- Local database storage
- Web dashboard for viewing collected data
- Environmental danger detection concept

## Project status
